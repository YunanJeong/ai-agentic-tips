| 경로 | 내용 |
|------|------|
| `claude-code/` | **Claude Code 부트스트랩 킷** — 새 환경 재구축용 전역 지침·권한·스킬 설정 원본 |

| `harness-engineering.md` | 하네스(컨텍스트·도구·권한) 관점의 설계 정리 |

새 머신·새 계정에 Claude Code를 설치할 때는 `claude-code/README.md` 부터 본다.
